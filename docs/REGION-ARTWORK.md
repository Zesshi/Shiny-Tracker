# Region artwork

Nine original painted panoramas generated with the built-in image generation tool. The original JPG placeholders have been replaced by local WebP assets.

The exports are 1440 pixels wide, WebP quality 80. Combined size: 817,340 bytes (0.78 MiB). No runtime image transformation or additional service is used. Existing first-view caching and unmounted collapsed grids are preserved.

The generation registry includes optional vertical crop focal points so taller
landmarks stay in frame on wide desktop headers. Title-side shading and the
progress badge background are CSS layers; the artwork remains reusable without
interface elements baked in.

## Exact generation prompts

The same style and composition brief was used for all nine images. Each region was a separate built-in generation request. No generated text or interface chrome is baked into the images.

### Kanto

Use case: stylized-concept.
Asset type: clean standalone landscape backdrop for an adventure field-journal app; artwork only, not a UI mockup.
Style/medium: exquisitely painted cinematic anime game environment key art, nostalgic adventure field journal, refined visible brushwork and crisp environmental detail with atmospheric depth, premium hand-painted illustration. Restrained luminous colors.
Composition/framing: extremely wide 3:1 panorama, ideally 1536x512 pixels. The app center-crops this into a shallow panorama. Keep all important landscape forms inside a broad horizontal band close to the vertical center, roughly 35–65% height. Place the principal landmark at center-right, 55–75% horizontal, below the sky. Leftmost 30% must be naturally darker, low contrast, calm environmental shapes suitable for a white title overlay. Keep the rightmost edge subdued for a progress overlay. Still richly colored and luminous in the center, never blanket-dark.
Constraints: original environment art; no people, no characters, no Pokémon or other creatures; no text, typography, logos, UI, borders, watermarks or lettering.
Primary request: Create the Kanto region backdrop.
Scene/backdrop and lighting: Verdant Japanese countryside, winding path out of a tiny red-roofed town, layers of forest and rounded mountains recalling Mount Moon, subtle coastal glints. Soft jade and sky-blue early morning, quiet promise of a first adventure.
